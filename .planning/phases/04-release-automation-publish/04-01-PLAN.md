<objective>
Run the D-02 manual org/transfer gate FIRST — it is the blocking prerequisite for all Phase-4 publish work (RLS-01). Create the `willram` GitHub org, confirm its name is actually available, transfer the existing `willramanand/litkit` repo into it (preserving history), re-point the local git remote, and confirm the org owns the repo. Until this gate passes, nothing else in Phase 4 may run: GitHub Packages requires the `@willram` npm scope to equal the repo-owning account, so every `@willram/*` publish 403s without it.

Purpose: Establish `@willram` scope ownership (the one external, unverifiable risk in this phase) before any auth-bearing or config work.
Output: A `willram` org owning `willram/litkit`, a re-pointed local `origin` remote, and a confirmed-ownership signal that unblocks Wave 2.
</objective>
