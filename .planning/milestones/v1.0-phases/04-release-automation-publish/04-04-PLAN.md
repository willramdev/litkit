<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| maintainer's local machine → GitHub Packages | The one-shot publish runs locally with a classic PAT — outside CI's controls |
| classic PAT → registry | The PAT can write packages; it must be least-scoped and never committed |
| local working tree → published tarball | Whatever is on disk at publish time becomes the immutable 1.0.0 contract |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-10 | Tampering / Integrity | stale or broken local tree at publish | high | mitigate | `prepublishOnly: npm run typecheck && npm run build` (added in 04-02) fires per package on `changeset publish`, blocking a broken tree from shipping; optional `npm pack --dry-run` pre-flight |
| T-04-11 | Information Disclosure | classic PAT leakage | high | mitigate | PAT scoped `write:packages` ONLY, supplied via the maintainer's local ~/.npmrc, never committed to the repo; a single one-shot then release.yml/GITHUB_TOKEN owns 1.0.1+ |
| T-04-12 | Spoofing | wrong scope ownership → 403 | high | mitigate | The 04-01 org-ownership gate confirms `@willram` == repo owner before this publish, so the scope resolves and does not 403 |
| T-04-13 | Elevation of Privilege | accidental publish of the root private package | medium | mitigate | Root stays `private: true` (04-02) so `changeset publish` skips it; only the five workspace packages publish |
</threat_model>
